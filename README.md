# Task 11: Responsive Layout Using CSS Grid

## Project Description
I created a fully responsive web layout using CSS Grid and Flexbox. The project features a mobile-first design that adjusts from a vertical stack on mobile devices to a professional sidebar-and-content layout on desktops.

## Key Features Implemented
* **CSS Grid Areas**: Used `grid-template-areas` to clearly define the placement of the header, sidebar, main content, and footer.
* **Mobile-First Design**: Developed the base styles for small screens first and used media queries for desktop enhancements.
* **Hybrid Layout**: Combined CSS Grid for the overall page structure with Flexbox for internal component alignment (cards).
* **Responsive Testing**: Verified the layout using browser DevTools simulation for various screen sizes.
